# GI — Cleanroom Garment Inventory

Responsive web app (phone and laptop) that replaces manual garment counting in the Fab1 and Fab2 cleanrooms. Floor staff enter only the deliveries; garment issues are imported from the issuing system's Oracle database; stock on hand is calculated. The lead sees deliveries per period, issues per day and current stock. Data is stored in MariaDB.
